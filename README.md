# 🔮 ทำนายโชคชะตา (Fortune Prediction)

เว็บแอปพลิเคชันดูดวง เสี่ยงทายโชคชะตา และขอพรสิ่งศักดิ์สิทธิ์ออนไลน์ระดับพรีเมียม รวมศาสตร์พยากรณ์และพิธีกรรมมงคลจากหลากวัฒนธรรมไว้ในที่เดียว ทั้ง **ไพ่ยิปซี (Tarot)**, **ดูดวงวันเดือนปีเกิด**, **ทำนายกรุ๊ปเลือด**, **เซียมซีญี่ปุ่น (Omikuji)**, **เซียมซีไทยโบราณ (Thai Siamsi)** และ **ระบบขอพรสิ่งศักดิ์สิทธิ์ 3 วัฒนธรรม** (เทพเจ้าไทย, เทพเจ้าญี่ปุ่น, พระเจ้า) พร้อมดีไซน์ Mystic Dark Theme หรูหรา สวยงาม แอนิเมชันลื่นไหล เอฟเฟกต์แสง และระบบเสียงสังเคราะห์ Web Audio API

---

## ✨ ฟีเจอร์หลัก (Features)

### 1. 🧭 ไพ่ยิปซีพยากรณ์ (Tarot Reading)
- **สำรับไพ่ Major Arcana 22 ใบ** ครบถ้วนตามศาสตร์สากลโบราณ
- **รูปแบบการทำนายหลากหลาย**:
  - ☀️ **ดูดวงรายวัน (Daily)**: เสี่ยงทาย 1 ใบ พร้อมบทสรุปพลังงานประจำวัน
  - 🌙 **ดูดวงรายเดือน (Monthly)**: เปิดไพ่ 3 ใบ เจาะลึกอดีต/พื้นฐาน ปัจจุบัน และแนวโน้มอนาคต
  - 🌟 **ดูดวงรายปี (Yearly)**: เปิดไพ่ 4 ใบ ประเมิน 4 ไตรมาสของชีวิตตลอดทั้งปี
- **การคัดกรองมุมมองเฉพาะด้าน**: ภาพรวมทั้งหมด, การงาน & อาชีพ, การเงิน & โชคลาภ, ความรัก & ความสัมพันธ์, สุขภาพ & พลังกายใจ และคำแนะนำจากไพ่
- **เอฟเฟกต์และลูกเล่น**: สับไพ่แบบสุ่ม, เลือกไพ่จากสำรับ, แอนิเมชันเปิดไพ่ 3D, ระบบสุ่มอัตโนมัติ และบันทึกผลการทำนาย (Local Storage พร้อม TTL)

### 2. 🎂 ดูดวงวันเดือนปีเกิด (Birth Fortune & Astrology)
- **คำนวณและวิเคราะห์ดวงชะตาครอบคลุม 6 มิติ**:
  - 📅 **วันเกิดทั้ง 7 วัน** (รวมวันพุธกลางวัน / พุธกลางคืน ราหู)
  - ♈ **จักรราศี (Zodiac Sign)** ทั้ง 12 ราศี พร้อมธาตุประจำราศีและดาวประจำตัว
  - 🐉 **ปีนักษัตร 12 ปี** พร้อมธาตุประจำปีเกิด (ทอง/น้ำ/ไม้/ไฟ/ดิน)
  - 🔢 **เลขศาสตร์เส้นทางชีวิต (Life Path Number)** วิเคราะห์จุดแข็ง จุดอ่อน และภารกิจชีวิต
  - ⏰ **ช่วงเวลาตกฟาก (Birth Time)** คำนวณช่วงเวลาเกิดตลอด 24 ชั่วโมง
  - 🩸 **เชื่อมโยงศาสตร์กรุ๊ปเลือด** เสริมการทำนายบุคลิกภาพเชิงลึก
- **ข้อมูลเสริมมงคล**: เลขนำโชค, สีมงคล, สีที่ควรเลี่ยง, ทิศมงคล, อัญมณีประจำตัว, อาชีพที่เหมาะสม และคำเตือนชะตาชีวิต
- บันทึกวันเดือนปีเกิดเพื่อดูซ้ำได้สะดวกรวดเร็ว

### 3. 🩸 ทำนายตามกรุ๊ปเลือด (Blood Type Fortune & Psychology)
- **ถอดรหัสบุคลิกภาพ 4 กรุ๊ปเลือด (A, B, O, AB)** ตามหลักจิตวิทยาความเชื่อสากล
- **วิเคราะห์เจาะลึก 5 มิติ**:
  - 🌟 **ภาพรวมและบุคลิกภาพเด่น**: จุดแข็ง จุดอ่อน บุคลิกซ่อนเร้น และสไตล์การใช้ชีวิต
  - ❤️ **ความรักและความสัมพันธ์**: พฤติกรรมเมื่อตกหลุมรัก สิ่งที่ต้องการในความรัก และข้อควรระวัง
  - 💼 **การทำงานและเพื่อนร่วมงาน**: สไตล์การทำงาน สภาพแวดล้อมที่ส่งเสริม และประเภทงานที่ตอบโจทย์
  - 🥗 **สุขภาพและโภชนาการ**: ระบบย่อยอาหาร อาหารที่ถูกโฉลก และการออกกำลังกายที่เหมาะสม
  - 🔮 **ระบบคำนวณเคมีคู่แท้ (Compatibility Matcher)**: เปรียบเทียบระดับความเข้ากันได้แบบเปอร์เซ็นต์ระหว่างคู่กรุ๊ปเลือด พร้อมเคล็ดลับการปรับจูนความสัมพันธ์

### 4. ⛩️ เซียมซีญี่ปุ่น (Omikuji - おみくじ)
- จำลองการเสี่ยงทายใบเซียมซีตามธรรมเนียมศาลเจ้าชินโตโบราณ
- **เลือกศาลเจ้าชื่อดังได้ตามใจชอบ**: ศาลเจ้าเมจิ (โตเกียว), ศาลเจ้าฟูชิมิอินาริ (เกียวโต), ศาลเจ้าอิซึโมะไทฉะ (ชิมาเนะ)
- **ระดับดวงชะตาถูกต้องตามต้นตำรับ**: มหาโชค (大吉), โชคดี (吉), โชคปานกลาง (中吉), โชคเล็กน้อย (小吉), กึ่งโชค (半吉), โชคปลายแถว (末吉), เคราะห์ (凶)
- **วิเคราะห์ดวง 8 มิติ**: ความหวัง, การค้า/การเงิน, ความรัก/การแต่งงาน, การเรียน/สอบแข่งขัน, การเดินทาง, สุขภาพ, มิตรสหาย/คนรอบข้าง, เคหสถาน/การย้ายที่อยู่
- แอนิเมชันเขย่ากระบอกไม้และไม้เซียมซีพุ่งออกมา พร้อมลูกเล่น "ผูกใบเซียมซีปัดเป่าเคราะห์" ไว้กับรั้วศาลเจ้า

### 5. 📜 เซียมซีไทยโบราณ ๒๘ ใบ (Thai Siamsi)
- เสี่ยงทายเซียมซีครบถ้วน **๒๘ ใบเซียมซีไทยโบราณ**
- **เลือกสถานที่ศักดิ์สิทธิ์จำลอง**: วัดพระแก้ว, วัดโสธรวรารามวรวิหาร, ศาลเจ้าพ่อเสือ
- **บทกลอนและคำทำนาย**: บทกลอนสุภาษิตไพเราะ พร้อมคำแปลเข้าใจง่าย คำแนะนำเสริมบารมี และระดับดวงชะตา
- **ระบบเสี่ยงทาย "ไม้ปวย" (โปย/คว่ำหงาย)**: จำลองการโยนไม้เสี่ยงทายตามธรรมเนียมจีนเพื่อยืนยันว่าเทพเจ้ายินยอมให้คำทำนายหรือไม่ (ชั่ว = สำเร็จ, อิม = เทพยังไม่ตอบ, ยัง = หัวเราะ/ถามใหม่)

### 6. 🔥 ขอพรเทพเจ้าไทย (Thai Deities Blessing)
- รวมมหาเทพและสิ่งศักดิ์สิทธิ์ยอดนิยม: พระพิฆเนศ, ท้าวเวสสุวรรณ, พระแม่ลักษมี, พญาครุฑ, พระราหู
- เขียนคำอธิษฐานและเลือกเครื่องสักการะบูชา (ธูปเทียน, ดอกไม้, ผลไม้, นมสด)
- สวดบทบูชา/คาถาตามขั้นตอน พร้อมบทพรมงคลเฉพาะองค์เทพ
- ระบบเสียงระฆังวัด/ขันสวดมนต์ศักดิ์สิทธิ์ (Sacred Temple Chime) ด้วย Web Audio API

### 7. 🏛️ ขอพรเทพเจ้าญี่ปุ่น (Japan Blessing & Ema - 絵馬)
- ขอพรเทพเจ้าชินโต: เทพีอามาเทราสึ (Amaterasu), เทพเบนไซเตน (Benzaiten), เทพอินาริ (Inari Okami)
- **ระบบเขียนแผ่นป้ายเอมะ (Ema)**: เลือกแพทเทิร์นลวดลายแผ่นไม้เอมะมงคล เขียนคำขอพร และแขวนถวายศาลเจ้า
- **สั่นกระดิ่งซูซุ (Suzu Bell)**: จำลองเสียงกระดิ่งทองเหลืองศาลเจ้าญี่ปุ่นโบราณ และรับสาส์นพรมงคล

### 8. ✝️ ขอพรพระเจ้า (Christian Prayer & Scripture Blessing)
- เลือกพระลักษณะแห่งพระเจ้า: พระเจ้าแห่งความรัก (God of Love), พระเจ้าผู้ทรงเยียวยา (Jehovah Rapha), พระเจ้าผู้ทรงจัดเตรียม (Jehovah Jireh), องค์สันติราช (Prince of Peace)
- จุดเทียนอธิษฐานศักดิ์สิทธิ์ (Candle Lit Effect) เขียนคำอธิษฐานในใจ
- รับข้อพระคัมภีร์เสริมกำลังใจและพระสัญญามงคล
- ระบบเปิดอ่านและสวดบทอธิษฐานขององค์พระผู้เป็นเจ้า (The Lord's Prayer) พร้อมเสียงคอรัสประสาน (Celestial Chime)

### 9. 📖 สารานุกรมไพ่ยิปซี (Tarot Encyclopedia)
- คลังข้อมูลและภาพประกอบไพ่ Major Arcana 22 ใบ
- ค้นหาได้ทั้งชื่อภาษาไทย ภาษาอังกฤษ และคีย์เวิร์ด
- ระบบฟิลเตอร์ตามธาตุ: ดิน, น้ำ, ลม, ไฟ
- รายละเอียดเจาะลึก: สัญลักษณ์บนหน้าไพ่, ความหมายภาพรวม, การงาน, การเงิน, ความรัก และข้อคิดเตือนใจ

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 8](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Visual Effects**: [canvas-confetti](https://www.npmjs.com/package/canvas-confetti) & Custom Mystic Light Particle Bursts
- **Audio Synthesizer**: Web Audio API (สร้างเสียงระฆังวัด, กระดิ่งชินโต และคอร์ดประสานศักดิ์สิทธิ์แบบออฟไลน์โดยไม่ต้องโหลดไฟล์เสียงภายนอก)
- **Performance**: Dynamic `React.lazy` Code Splitting โหลดคอมโพเนนต์ตามหน้าเพื่อความรวดเร็ว

## 🚀 เริ่มต้นใช้งาน (Getting Started)

### ความต้องการของระบบ (Prerequisites)
- [Node.js](https://nodejs.org/) (เวอร์ชัน 18 ขึ้นไป แนะนำ LTS)
- ตัวจัดการแพ็กเกจ: `npm`, `pnpm` หรือ `yarn`

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. รันโหมด Development
```bash
npm run dev
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:5173` เพื่อเข้าใช้งาน

### 3. ตรวจสอบโค้ด (Linting)
```bash
npm run lint
```

### 4. Build สำหรับ Production
```bash
npm run build
```
ไฟล์ Production ที่ผ่านการ compile และ bundle จะถูกสร้างไว้ในโฟลเดอร์ `dist/`
